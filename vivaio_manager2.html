💾 Info Backup

Come funziona il backup:

  • 💾 Esporta Backup → Scarica un file JSON con tutti i tuoi dati
  • 📥 Importa Backup → Carica un file JSON per ripristinare i dati

📱 Su smartphone:

  • Il backup si scarica come file nella cartella Download
  • Per importare, clicca su "Importa Backup" e seleziona il file
  • Puoi salvare il backup su Google Drive, Dropbox o inviarlo via email

🔗 Sincronizzazione tra dispositivi:

  • Fai backup dal dispositivo A
  • Salva il file su cloud (Google Drive, Dropbox, ecc.)
  • Dal dispositivo B, fai import del file

🌐 Hosting su GitHub Pages:

  • Crea un repository su GitHub
  • Carica il file index.html
  • Vai su Settings → Pages → Branch main → Save
  • L'app sarà disponibile a: https://tuouser.github.io/tuorepo/
